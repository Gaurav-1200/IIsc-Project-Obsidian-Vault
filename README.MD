## Real-Time & Dual-System AI Agents - Obsidian Vault

This vault documents literature reviews, architectural designs, and notes on real-time conversational agents, dual-system cognitive routing (Fast & Slow / System 1 & 2), and talker-reasoner paradigms.

---

## 🧭 Vault Navigation
For easier access the vault is centralized around an **[[Index]] (./Reports/Index.MD)** that tracks milestones and houses executive weekly reports

**Directory Breakdown:**
* 📂 **`Reports/`** - Contains the Master Index, milestone trackers, and Weekly Progress Reports
* 📂 **`Notes/`** - Raw literature notes and concept breakdowns 
* 📂 **`Sources/`** - Original PDF research papers

## 💻 How to View This Vault
* **On GitHub (Quick View):** Simply navigate the folders above. GitHub natively renders all Markdown files, including the collapsible weekly reports.
* **In Obsidian (Full Experience):**
  1. Download this repository as a ZIP or clone it via Git.
  2. Open [Obsidian](https://obsidian.md/).
  3. Select **Open folder as vault** and choose the downloaded folder to enable interactive wikilinks and the knowledge graph.
