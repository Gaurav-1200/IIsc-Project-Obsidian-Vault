|**Jev / Non-Autoregressive Heads**|Single-pass discriminative classification head outputting discrete probabilities without text generation.|Original API relies on STT (latency bottleneck); requires custom training for native audio.|The O(1) latency architecture mapping latent embeddings directly to intent probabilities.|Replicate the classification head on an open-source audio-native model to bypass STT completely.|
|**RouteLLM**|Learns to route queries between a fast/weak and slow/strong model using preference data.|Designed for static one-off text queries to save dollar costs, ignoring running processes.|The supervised training framework and threshold routing baseline.|Add the slow layer's pending-graph state and a disruption cost term to the routing function.|
|**CP-Router (Conformal Prediction)**|Uses conformal prediction to dynamically route queries with mathematical guarantees on error rates.|Evaluated mostly on static text QA; requires a perfectly representative calibration dataset.|Conformal thresholding to guarantee a bounded failure rate for the fast layer.|Adapt the safety label to penalize false interruptions (interrupting when unnecessary) and missed interruptions.|
|**Learning to defer**|Mathematical framework for deciding when a local system should defer to an expert based on a cost function.|Assumes static, single decisions rather than ongoing asynchronous processes.|The formal framing, consistency arguments, and cost-based deferral logic.|Define "cost of expert" specifically as the disruption penalty to the slow layer (wasted compute, context reset).|
|**Rule-based & Heuristic Switches**|Hand-written switching rules using fixed thresholds (e.g., volume spikes, silence duration).|Brittle; fails to capture semantic urgency, tone, or conversational prosody.|Fast, zero-compute acoustic overrides (like VAD interrupts) as your absolute baseline.|Sweep thresholds systematically to create a tuned fallback safety layer underneath the neural classifier.|
|**Predictive Entropy / Uncertainty Routing**|Uses the fast model's internal uncertainty (entropy/logprobs) to escalate complex inputs to the slow model.|Historically limited to offline text features; closed APIs often hide logprobs.|Using the fast model's uncertainty score as a direct routing feature.|Extract entropy directly from the audio-latent space to trigger the slow layer when speech intent is ambiguous.|
