# Setup 2 For Slow Layers

| Option                                          | What it proposes                                                    | Limitation                                                                                    | Adapting to our project                                                                                        | Comments                                                                               |
| ----------------------------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **LangGraph + ReAct**                           | - Stateful multi-turn graph  <br>- Native persistence & checkpoints | - Rigid turn based execution              - State transitions cannot be interrupted mid-node. | - Core Slow Layer Engine <br>- Helps in Phase 4 latency filling                                                | - Standard  baseline complex reasoning orchestration                                   |
| **LlamaIndex Workflows**                        | - Event-driven, asynchronous agent graph architecture               | -Harder to visualize/debug complex loops compared to LangGraph                                | - **Fluid/Async Controller**  <br>- Allows the slow layer to emit partial updates to the fast layer via events | Event-driven nature handles fast-layer micro-interruption states                       |
| **Voice Pipelines** _(LiveKit / Pipecat)_       | - Integrated ASR/TTS wiring  <br>- Turn detection & VAD handling    | - Plugin/version instability  <br>- Tight lock-in to framework primitives                     | - **Live Harness Infrastructure**  <br>- Audit framework interruption hooks for barge-in                       | - Vital for bridging the fast-layer audio stream to slow-layer text tools              |
| **Cascaded Wrapper** _(ASR + TTS / CosyVoice2)_ | - Traditional modular speech-text-speech stack                      | - Massive accumulated latency  <br>- Destroys native barge-in capabilities                    | - Benchmark baseline to measure native Omni model latency gains                                                | - **Flagged:** Poor fit for a real-time conversational agent; use purely as a control  |
